# 面包板逐孔组装 / Breadboard Layout

本文针对最常见的 **MB-102 / 830 孔面包板（2.54 mm 间距，左侧 a-e、右侧 f-j，中间沟槽）**。
不同厂家可能把电源轨从中间断开，或把行号印在另一侧；行号只是定位参照，最终以模块丝印和 ESP32-C3 引脚丝印为准。

## 一、需要购买的具体物料

| 数量 | 建议型号或规格 | 说明 |
|---:|---|---|
| 1 | MB-102 / 830 tie-point 面包板 | 带红蓝电源轨，左右各一组更方便 |
| 1 | ESP32-C3-DevKitM-1 | USB-C 版本，板上必须有 `3V3`、`GND`、`4`、`5`、`8` 丝印 |
| 1 | SHT30 breakout | 4 针：VCC/VIN、GND、SDA、SCL |
| 1 | ENS160 breakout | 4 针 I2C 版本：VCC/VIN、GND、SDA、SCL |
| 1 | SSD1306 0.96 inch 128x64 I2C | 4 针版本：VCC、GND、SDA、SCL，地址通常 `0x3C` |
| 1 | WS2812B 单颗模块 | 3 针：VCC、DIN、GND；先确认电压规格 |
| 1 | 330 ohm，1/4 W 电阻 | 串在 GPIO8 到 DIN 之间 |
| 1 | 100 uF / 6.3 V 或更高电压电解电容 | 并在 WS2812 的 VCC/GND 之间，正极接 VCC |
| 1 套 | 22 AWG 实心跳线或公对公杜邦线 | 面包板内部连接 |
| 1 套 | 公对母杜邦线 | 连接 ESP32 或带母座的模块 |
| 1 | USB-C 数据线 | 烧录和供电 |

不要购买没有 `SDA/SCL` 标注的 ENS160 模块，也不要把裸 ENS160 芯片直接插入面包板。

## 二、先建立坐标和电源轨

把面包板竖放，数字从上到下为 `1` 到 `63`，左半边孔为 `a b c d e`，右半边孔为 `f g h i j`。
同一行的 `a-e` 五个孔相通，`f-j` 五个孔相通；中间 `e-f` 不相通。

俯视布局如下（不是按比例绘制，但模块和行号对应下表）：

```text
左电源轨  + =============================================== 右电源轨 +
左半区       a b c d e       中间沟槽       f g h i j       右半区
行 20      [SDA 总线 a20-e20]                 <跨沟槽跳线>  OLED SDA
行 21      [SCL 总线 a21-e21]                 <跨沟槽跳线>  OLED SCL
行 30      [SHT30 排针 b30-b33]                [OLED 排针 g30-g33]
行 38      [ENS160 排针 b38-b41]               [WS2812 排针 g38-g40]
行 63      - =============================================== -
```

ESP32-C3 横跨中间沟槽，放在行 8-24 附近；它的具体排针孔位不写死，跳线直接接到板上印有 `3V3`、`GND`、`4`、`5`、`8` 的引脚。

1. ESP32 横跨中间沟槽，USB-C 朝上；不要把 ESP32 的整块 PCB 插进孔里，只让两排排针分别落在沟槽两侧。
2. ESP32 `3V3` 用红线接到面包板上方红色 `+` 电源轨。
3. ESP32 `GND` 用黑线接到面包板上方蓝色 `-` 电源轨。
4. 如果红/蓝电源轨在中间断开，用跳线分别桥接左段和右段；不确定时用万用表通断档测量。
5. 传感器和 OLED 全部使用这个 `3V3` 与 `GND`。先不要接 WS2812 的电源。

## 三、模块插入位置

下面的行号是假定模块带一排 2.54 mm 排针。模块的引脚顺序可能不同，所以**插入前先看模块丝印，按名称接，不按颜色猜**。

| 模块 | 建议插入区域 | 四针/三针在面包板上的目标孔 |
|---|---|---|
| SHT30 | 左侧，靠上 | `b30-b33`，依次放入模块的四根排针 |
| ENS160 | 左侧，靠下 | `b38-b41`，依次放入模块的四根排针 |
| SSD1306 | 右侧，靠上 | `g30-g33`，依次放入模块的四根排针 |
| WS2812B | 右侧边缘 | `g38-g40`，依次放入模块的三根排针 |

如果某个模块排针方向使相邻孔放不下，保持模块位置不变，使用公对母线从模块丝印引脚连接到下面的总线孔；不要强行改变模块供电脚位置。

## 四、每一根线的起点和终点

下面把总线固定在左半边的空闲孔，便于检查。每根线两端都插入同一侧 `a-e` 的相通孔，或直接接到电源轨。

### 3.3 V 和 GND

| 线 | 起点 | 终点 |
|---|---|---|
| SHT30 电源 | SHT30 丝印 `VCC/VIN` | 红色 `+` 电源轨 |
| SHT30 地 | SHT30 丝印 `GND` | 蓝色 `-` 电源轨 |
| ENS160 电源 | ENS160 `VCC/VIN` | 红色 `+` 电源轨 |
| ENS160 地 | ENS160 `GND` | 蓝色 `-` 电源轨 |
| OLED 电源 | OLED `VCC` | 红色 `+` 电源轨 |
| OLED 地 | OLED `GND` | 蓝色 `-` 电源轨 |

### I2C 总线

用两种颜色区分：蓝色表示 SDA，绿色表示 SCL。

| 线 | 起点 | 终点 |
|---|---|---|
| SDA 主线 | ESP32-C3 丝印 `GPIO4` | 左侧 `a20` |
| SHT30 SDA | SHT30 丝印 `SDA` | `a20` |
| ENS160 SDA | ENS160 丝印 `SDA` | `a20` |
| OLED SDA | OLED 丝印 `SDA` | `a20` |
| SCL 主线 | ESP32-C3 丝印 `GPIO5` | 左侧 `a21` |
| SHT30 SCL | SHT30 丝印 `SCL` | `a21` |
| ENS160 SCL | ENS160 丝印 `SCL` | `a21` |
| OLED SCL | OLED 丝印 `SCL` | `a21` |

`a20-e20` 是同一组电气连接，`a21-e21` 是另一组电气连接。不要把 SDA 线插到第 21 行，也不要把 SCL 线插到第 20 行。右侧模块到 `a20/a21` 要用跨沟槽长跳线，不能假设 `f20` 与 `e20` 相通。

### WS2812 数据线

1. ESP32-C3 丝印 `GPIO8` -> 电阻一脚。
2. 电阻另一脚 -> WS2812 丝印 `DIN`，方向为 `DIN` 而不是 `DOUT`。
3. WS2812 `GND` -> 蓝色 `-` 电源轨。
4. WS2812 `VCC`：模块明确支持 3.3 V 才接红色 `+` 轨；要求 5 V 的模块接 USB 供电端的 `VBUS/5V`，但仍接同一个蓝色 `-` 地轨。
5. 100 uF 电容直接跨在 WS2812 两个电源脚附近：电容 `+` 接 VCC，电容 `-` 接 GND。

## 五、通电顺序

### 第一次：只验证 OLED

只连接 ESP32、红/蓝电源轨和 OLED 的 VCC/GND/SDA/SCL。上电后串口应扫描到 `0x3C`，OLED 显示 `Air Monitor`。不对就断电，先检查 SDA/SCL 是否反接。

### 第二次：加入 SHT30

断电，把 SHT30 插入 `b30-b33` 区域，按丝印接到 `a20`（SDA）、`a21`（SCL）、红色 `+`（VCC）、蓝色 `-`（GND）。重新上电应新增 `0x44`。

### 第三次：加入 ENS160

断电，把 ENS160 插入 `b38-b41` 区域，按丝印接入同一组电源和 I2C 总线。重新上电应新增 `0x53`。首次工作会预热，几分钟内 AQI/eCO2 不可用是正常的。

### 第四次：加入 WS2812

断电，先接电容，再接 330 ohm 电阻和 DIN，最后接 WS2812 电源。上电观察紫色闪烁后，传感器可用时应按 AQI 显示绿/黄/红。

## 六、上电前逐项勾选

- [ ] ESP32 横跨沟槽，排针没有插在同一侧短接。
- [ ] 三个 I2C 模块的 VCC 都是 3.3 V。
- [ ] `GPIO4 -> SDA`，`GPIO5 -> SCL`，没有交叉。
- [ ] SHT30、ENS160、OLED、WS2812 全部共地。
- [ ] 电阻在 GPIO8 和 WS2812 `DIN` 之间，不在电源线上。
- [ ] 电容正极接 WS2812 VCC，负极接 GND。
- [ ] 5 V 没有接到 ESP32 `3V3`、SHT30、ENS160 或 OLED。
- [ ] 第一次上电前用万用表测 3V3 与 GND 不短路。
